# Τεχνική Περιγραφή Σταθμού Παρακολούθησης Καιρού ECE Patras

Το έργο αυτό αποτελεί έναν αυτόνομο σταθμό παρακολούθησης θερμοκρασίας και υγρασίας που βασίζεται σε μικροελεγκτή NodeMCU (ESP8266/ESP32) και τον αισθητήρα DHT22. Το σύστημα είναι αναπτυγμένο σε περιβάλλον MicroPython και ενσωματώνει δυνατότητες τοπικού Web Server, καταγραφής δεδομένων, αποστολής ειδοποιήσεων μέσω ηλεκτρονικού ταχυδρομείου και απομακρυσμένης πρόσβασης μέσω διαδικτύου.

Το project υλοποιήθηκε ως εργασία για το τμήμα Ηλεκτρολόγων Μηχανικών και Τεχνολογίας Υπολογιστών του Πανεπιστημίου Πατρών.

## Λειτουργικά Χαρακτηριστικά

* **Διαδικτυακό Ταμπλό Διασύνδεσης:** Ένας ενσωματωμένος Web Server στον μικροελεγκτή σερβίρει μια responsive σελίδα παρουσίασης των μετρήσεων.
* **Διαδραστική Οπτικοποίηση:** Η βιβλιοθήκη Chart.js χρησιμοποιείται για την απεικόνιση των ιστορικών μεταβολών θερμοκρασίας και υγρασίας σε πραγματικό χρόνο.
* **Καταγραφή και Διαχείριση Μνήμης:** Οι μετρήσεις αποθηκεύονται στο αρχείο log.txt. Η μεταφορά των δεδομένων γίνεται τμηματικά (chunked transfer) για την αποτροπή σφαλμάτων τύπου MemoryError λόγω των περιορισμένων πόρων της RAM.
* **Υπηρεσία Ειδοποιήσεων:** Το σύστημα υποστηρίζει την αποστολή τρεχουσών μετρήσεων μέσω πρωτοκόλλου SMTP και χρήσης raw sockets με τους διακομιστές της Gmail.
* **Διαχείριση Δικτύωσης:** Ο μικροελεγκτής λειτουργεί σε διπλό mode. Αναζητά σύνδεση σε σταθμό Wi-Fi (STA mode) και, σε περίπτωση αποτυχίας, ενεργοποιεί αυτόνομα τοπικό σημείο πρόσβασης (AP mode) με την ονομασία ECE_Patras.

## Απαιτήσεις Υλικού

* Μικροελεγκτής NodeMCU (ESP8266) ή ESP32.
* Αισθητήρας θερμοκρασίας και υγρασίας DHT22.
* Αντίσταση pull-up 10kΩ για τη γραμμή δεδομένων (εφόσον δεν περιλαμβάνεται στο module του αισθητήρα).
* Καλώδια σύνδεσης και πλακέτα δοκιμών (breadboard).

Η συνδεσμολογία περιλαμβάνει τη σύνδεση των ακροδεκτών τροφοδοσίας του αισθητήρα στα 3.3V και GND του μικροελεγκτή, και του ακροδεκτή δεδομένων στην ψηφιακή θύρα GPIO 2 (D4).

## Απαιτήσεις Λογισμικού

* Firmware MicroPython εγκατεστημένο στον μικροελεγκτή.
* Το εργαλείο mpremote για τη διαχείριση, μεταφορά αρχείων και αλληλεπίδραση με το REPL του μικροελεγκτή μέσω γραμμής εντολών.
* Περιβάλλον Python 3.x στον υπολογιστή για την εκτέλεση του βοηθητικού script αυτοματοποίησης.
* Λογισμικό ngrok για τη δημιουργία ασφαλούς τούνελ προς το διαδίκτυο.
* Η βιβλιοθήκη pyserial της Python στον υπολογιστή για τη σειριακή επικοινωνία.

## Δομή Αρχείων Συστήματος

* **boot.py:** Το αρχείο αρχικοποίησης που διαχειρίζεται τη σύνδεση στο τοπικό δίκτυο Wi-Fi ή τη δημιουργία του Access Point.
* **main.py:** Ο πυρήνας του Web Server που διαχειρίζεται τις συνδέσεις socket, επεξεργάζεται τα HTTP αιτήματα και επιστρέφει την HTML/JS σελίδα σε κομμάτια.
* **sensor_log.py:** Το υποσύστημα που αναλαμβάνει την περιοδική ανάγνωση του αισθητήρα, το caching των μετρήσεων και τη διαχείριση του αρχείου log.txt.
* **secrets.py:** Το αρχείο παραμετροποίησης που περιέχει τα διαπιστευτήρια του Wi-Fi, του λογαριασμού SMTP και τον κωδικό πρόσβασης του διαχειριστή.
* **setup_and_tunnel.py:** Script που εκτελείται στον υπολογιστή. Αναλαμβάνει να στείλει σήμα διακοπής στον μικροελεγκτή, να καθαρίσει το ιστορικό καταγραφών, να πραγματοποιήσει soft reset και να ξεκινήσει τη δημόσια δρομολόγηση.

## Διαδικασία SETUP και Αυτοματοποιημένης Λειτουργίας

Η διαχείριση του μικροελεγκτή βασίζεται στο εργαλείο mpremote, το οποίο επιτρέπει τον απόλυτο έλεγχο χωρίς την ανάγκη γραφικού περιβάλλοντος. 

Το script setup_and_tunnel.py αυτοματοποιεί τη διαδικασία προετοιμασίας της παρουσίασης. Όταν εκτελείται στον υπολογιστή, συνδέεται σειριακά με το NodeMCU, στέλνει σήμα Ctrl+C για τη διακοπή του main.py, διαγράφει το παλιό αρχείο log.txt και προκαλεί soft reset με Ctrl+D ώστε ο μικροελεγκτής να ξεκινήσει καθαρός, συνδεδεμένος στο hotspot (IP 10.12.143.54). 

Ταυτόχρονα, το script εκκινεί το ngrok στον υπολογιστή, το οποίο δεσμεύει το σταθερό domain endanger-trickily-excavator.ngrok-free.dev και προωθεί την εξωτερική κίνηση στη θύρα 80 του μικροελεγκτή, καθιστώντας τον σταθμό προσβάσιμο παγκοσμίως.
